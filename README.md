# Easy English Grammar Hub

Тренажёр английской грамматики для русскоязычных учеников (уровень A1–A2).
Сайт: https://pitbool7517-beep.github.io/Easy-English-Grammar-Hub/

## Разделы

| Раздел | Что внутри | Заданий в прогрессе |
|---|---|---|
| Времена глаголов | Таймлайн Past / Present / Future Simple, формулы, мини-тест | 9 |
| Глагол TO BE | Конструктор am / is / are, тесты на утверждение, отрицание, вопрос | 9 |
| Притяжательный падеж | Сравнение 's и s', упражнение «вставь апостроф» | 9 |
| Артикли A / AN | Шпаргалка, тренажёр «первый звук», 3 проверки | 22 |
| Present Simple (+) | Шпаргалка, конструктор -s / -es / -ies, 3 проверки | 23 |
| Проверка текста | Поиск ошибок и перевод (внешние сервисы, см. ниже) | — |
| Произношение | Озвучка, транскрипция US/UK, проверка написания | — |

## Где хранятся данные

Только в браузере пользователя (`localStorage`). Сервер не используется, у каждого
браузера и устройства свои данные.

| Ключ | Что в нём |
|---|---|
| `eegh-data-v2` | Текущие данные (схема 2): `progress` — решённые задания с датой, `topics`, `items` — свои темы и карточки, `reviews` — история повторений, `settings`, `meta` |
| `eegh-progress-v1` | Старый формат `{ "t1": true }`. При первом запуске переносится в v2 и **не удаляется** |
| `eegh-data-v2-before-import` | Состояние до последнего импорта (для кнопки «Вернуть как было») |
| `eegh-data-v2-damaged-<время>` | Повреждённые данные, если их не удалось прочитать (не стираются) |

- Раздел **«Мои данные»**: «Скачать копию» (файл `easy-english-backup-ГГГГ-ММ-ДД.json`)
  и «Загрузить из файла» с предпросмотром и выбором «Объединить» / «Заменить».
- Перенос на другое устройство: скачать копию → открыть сайт там → загрузить файл.
- Приложение просит браузер хранить данные постоянно (`navigator.storage.persist`).
- Сброс прогресса требует подтверждения.

## Внешние сервисы

Используются только в разделах «Проверка текста» и «Произношение», по нажатию кнопки:
LanguageTool (проверка), MyMemory (перевод), Wiktionary, Free Dictionary API, Datamuse (транскрипции).
Введённый текст отправляется этим сервисам. Без интернета работает упрощённая встроенная проверка.

## Проверка перед публикацией

```bash
npm i -D playwright
npx playwright install chromium
node tests/smoke.js   # разделы, прогресс, сброс, телефон, сбой загрузки
node tests/data.js    # перенос v1→v2, экспорт, импорт, повреждённые файлы и данные
```

Тест проверяет: загрузку, все разделы, засчёт ответов в «Артиклях» и Present Simple,
сохранение после перезагрузки, подтверждение сброса, отсутствие прокрутки вбок на телефоне
и сообщение при сбое загрузки библиотек.
