# Easy English Grammar Hub

Тренажёр английской грамматики для русскоязычных учеников (уровень A1–A2).
Сайт: https://pitbool7517-beep.github.io/Easy-English-Grammar-Hub/

## Разделы

| Раздел | Что внутри | Заданий в прогрессе |
|---|---|---|
| Времена глаголов | Таймлайн Past / Present / Future Simple, формулы, мини-тест | 9 |
| Глагол TO BE | Конструктор am / is / are, тесты на утверждение, отрицание, вопрос | 9 |
| Притяжательный падеж | Сравнение 's и s', упражнение «вставь апостроф» | 9 |
| Артикли A / AN | Шпаргалка, тренажёр «первый звук», 3 проверки | 22 |
| Present Simple | Вкладки «Правила» (утверждение и отрицание, -s / -es, don't / doesn't, конструктор + и −), «Упражнения» (выбор формы, ввод формы, don't/doesn't, отрицание, найди и исправь, перевод) и «Итоговый тест» из 10 вопросов | 55 |
| Adverbs of Frequency | Шкала always → never (100–0%), место наречия (перед глаголом, после am/is/are), How often; выбор наречия, место в предложении, сборка предложения из слов, перевод, итоговый тест из 10 вопросов | 39 |
| Проверка текста | Поиск ошибок и перевод (внешние сервисы, см. ниже) | — |
| Произношение | Озвучка, транскрипция US/UK, проверка написания | — |
| Повторение | Занятия на 10/20 карточек или 5/10/15 минут по выбранным темам: ввод ответа, перевод с самооценкой, пропуск в примере, правила; ошибки повторяются в конце; «Только трудные», история по дням | — |
| Моя база | Свои слова, выражения и правила по темам: добавление, вставка списком, правка, поиск, статистика и метка «трудная» | — |
| Мои данные | Резервная копия в файл и загрузка из файла, лимит перевода, проверка внешних сервисов | — |

Меню: группы «Грамматика», «Тренажёры», «Мои материалы» раскрываются по нажатию на заголовок; одновременно открыта одна группа, группа текущего раздела раскрыта.

## Где хранятся данные

Только в браузере пользователя (`localStorage`). Сервер не используется, у каждого
браузера и устройства свои данные.

| Ключ | Что в нём |
|---|---|
| `eegh-data-v2` | Текущие данные (схема 2): `progress` — решённые задания с датой, `topics`, `items` — свои темы и карточки, `reviews` — история повторений, `settings`, `meta` |
| `eegh-progress-v1` | Старый формат `{ "t1": true }`. При первом запуске переносится в v2 и **не удаляется** |
| `eegh-data-v2-before-import` | Состояние до последнего импорта (для кнопки «Вернуть как было») |
| `eegh-data-v2-damaged-<время>` | Повреждённые данные, если их не удалось прочитать (не стираются) |

- Раздел **«Мои данные»**: «Скачать копию» (файл `easy-english-backup-ГГГГ-ММ-ДД.json`)
  и «Загрузить из файла» с предпросмотром и выбором «Объединить» / «Заменить».
- Перенос на другое устройство: скачать копию → открыть сайт там → загрузить файл.
- Приложение просит браузер хранить данные постоянно (`navigator.storage.persist`).
- Сброс прогресса требует подтверждения.

**Трудная карточка** — среди трёх последних ответов есть ошибка. Перестаёт быть трудной после двух верных ответов подряд (опечатка считается верным).

## Внешние сервисы

Используются только в разделах «Проверка текста», «Произношение» и в кнопке «Подставить» транскрипцию, по нажатию кнопки.
Введённый текст отправляется этим сервисам. Без интернета работает упрощённая встроенная проверка.

| Сервис | Для чего | Ограничения |
|---|---|---|
| LanguageTool | Проверка текста и написания | 20 запросов в минуту с одного IP; обязательна видимая ссылка на сервис |
| MyMemory | Перевод | 5 000 символов в день, 50 000 — если указать e-mail в «Моих данных» (хранится только в браузере) |
| Wiktionary | Транскрипции US / UK | Ограничение частоты запросов на IP |
| Free Dictionary API | Транскрипции, записи носителей | Лимиты не опубликованы |
| Datamuse | Запасная транскрипция и подсказки | С 2027 года нужен ключ API. Без ключа приложение продолжит работать на остальных сервисах (проверено тестом) |

Проверить, отвечают ли сервисы у конкретного пользователя: «Мои данные» → «Проверить сервисы» → «Скопировать результат».

## Публикация сайта

Сайт публикуется сценарием GitHub Actions `.github/workflows/pages.yml`:
при каждом push в `main` он проверяет файлы сайта и выкладывает только `index.html` и `hero.webp`
(тесты и служебные файлы на сайт не попадают). Ожидание выкладки — до 20 минут.

- В настройках репозитория: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
- Запустить выкладку вручную: **Actions → Deploy site → Run workflow**.
- Если выкладка зависла на стороне GitHub, достаточно запустить её вручную ещё раз.

## Проверка перед публикацией

```bash
npm i -D playwright
npx playwright install chromium
node tests/smoke.js   # разделы, прогресс, сброс, телефон, сбой загрузки
node tests/data.js    # перенос v1→v2, экспорт, импорт, повреждённые файлы и данные
node tests/base.js    # «Моя база»: темы, карточки, вставка 50 строк, поиск, правка, удаление
node tests/review.js  # «Повторение»: проверка ответов, сессия, прерывание, таймер
node tests/history.js # трудные карточки, история по дням
node tests/services.js # подсказки написания, простые правила, проверка сервисов, отказ Datamuse
node tests/psimple.js # раздел Present Simple: правила, упражнения, тест, сохранность прогресса
node tests/adverbs.js # раздел Adverbs of Frequency: грамматика примеров, упражнения, тест
node tests/nav.js     # раскрывающееся меню: группы, одна открытая, телефон
node tests/menubtn.js # кнопка ☰ в шапке: контраст в светлой и тёмной теме, все состояния
```

Тест проверяет: загрузку, все разделы, засчёт ответов в «Артиклях» и Present Simple,
сохранение после перезагрузки, подтверждение сброса, отсутствие прокрутки вбок на телефоне
и сообщение при сбое загрузки библиотек.
